## §5. Kết quả kiểm chứng trực tiếp Sóng 5 QA (`AC-4`, `AC-5`, `AC-6`, `AC-7`)

### 5.1. Smoke đầu-cuối sống với backend thật (`AC-4`)

Kịch bản đầy đủ trên cả hai nền tảng nối backend Spring Boot của `integration/app-hoc-vien` + Keycloak `thi360-mobile` + Mailpit trên host `cty`:
1. Đăng ký tài khoản học viên mới → đọc mã OTP 6 chữ số trực tiếp từ Mailpit API → xác minh OTP → vào Trang chủ.
2. Mở Tài khoản → xác minh họ tên, tên đăng nhập, email và huy hiệu `"Email đã xác minh"`.
3. Đổi mật khẩu tự nguyện (`password1` → `password2`) → xác minh phiên đăng nhập vẫn được giữ.
4. Đăng xuất → xác minh token đã xóa → đăng nhập lại bằng `password2` → đăng xuất.
5. Quên mật khẩu → đọc token đặt lại từ email trong Mailpit → mở app bằng deep link `/reset-password?token=...` → đặt `password3` → xác minh quay về Đăng nhập kèm banner xác nhận → đăng nhập lại bằng `password3` → đăng xuất.
