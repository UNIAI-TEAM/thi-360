Lời giải

Nhân liên hợp ở tử số: 2x − √(3x + 1) = (4x2 − 3x − 1) / (2x + √(3x + 1)) = (x − 1)(4x + 1) / (2x + √(3x + 1)).

Mẫu số x2 − 1 = (x − 1)(x + 1). Rút gọn x − 1 rồi thay x = 1: giới hạn bằng 5 / ((2 + 2)(1 + 1)) = 5/8. Chọn C.
